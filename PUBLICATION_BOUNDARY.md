# Paquete de replicación metodológica INI

**Modalidad B: especificación metodológica sin publicación de código fuente.** Este paquete permite construir una implementación independiente sobre datos propios o autorizados; no contiene software histórico, datos del TFM, imágenes, identificadores reales ni modelos entrenados.

## Exclusiones obligatorias
Cero código fuente o notebooks internos; cero checkpoints/modelos; cero imágenes, CSV real, nombres/IDs reales, hashes de imágenes, rutas locales, secretos o metadatos restringidos. Los ejemplos son sintéticos. No se publica repositorio remoto desde P01.

## Permitido
Especificaciones declarativas, tablas de parámetros, contratos de I/O, fórmulas, pseudocódigo no equivalente a source y comandos genéricos para una futura implementación independiente.
