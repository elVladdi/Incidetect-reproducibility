# Frontera de publicación

Este repositorio público contiene una **especificación metodológica** destinada a construir implementaciones nuevas con datos propios o autorizados.

## Publicado

- documentación de preparación y particionado de datos;
- parámetros y decisiones metodológicas recuperadas;
- especificaciones 01–08;
- reglas de evaluación y selección de umbral;
- referencias de resultados históricos agregados;
- documentación de límites de evidencia;
- ejemplo sintético de estructura de dataset;
- prompt maestro para una implementación independiente;
- manifiesto SHA-256 del paquete.

## No publicado

Por restricciones de acceso/no publicación y por la finalidad de este paquete, no se incluyen:

- las imágenes utilizadas en el estudio original;
- CSV o metadata reales;
- nombres o identificadores operativos reales;
- hashes de imágenes restringidas;
- código fuente o notebooks históricos;
- checkpoints, pesos o modelos entrenados;
- rutas locales, credenciales, secretos o metadatos privados.

Los ejemplos públicos son sintéticos.

## Qué significa esta frontera

El repositorio permite **replicación metodológica externa**, no reproducción forense de una corrida histórica. Un tercero debe aportar datos propios/autorizados, entrenar sus propios modelos y reportar sus propios resultados.

El repositorio público existe y se versiona mediante commits. El commit histórico de la primera publicación se conserva en el historial; las correcciones de documentación se publican en commits posteriores, sin reescritura de historia.

No se incluye una licencia elegida automáticamente como parte de esta ronda documental.
